## 22 grados de libertad aparentes. 24 objetivos arbitrarios garantizados.

H6 demuestra que para **cualquier** conjunto **H ⊆ F₂¹²** con **|H| ≤ 24**, existe una aplicación

**q : F₂⁶ → F₂¹²**

cuyas coordenadas tienen grado algebraico como máximo 2 y cuya imagen contiene a **H**.

Por lo tanto, **h(6) ≥ 25**.

En lenguaje simple: la cuenta básica sugiere una barrera natural de 22. El teorema garantiza 24, no agregando coeficientes, sino eligiendo adaptativamente los puntos de entrada para hacer coincidir las dependencias inevitables con relaciones que los objetivos ya poseen.
