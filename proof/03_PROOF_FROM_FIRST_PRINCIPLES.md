# 03 — PROOF FROM FIRST PRINCIPLES

Throughout, all vector spaces and codes are over `F_2`.

## Lemma 1 — Reduction to 24 distinct targets `[HUMAN_PROOF]`

It is enough to prove the interpolation statement for exactly 24 target points. Any smaller target set can be enlarged to 24 distinct points of `F_2^12`.

Assume for contradiction that a 24-set `H` is not contained in the image of any quadratic map.

## Lemma 2 — Translation normalization `[HUMAN_PROOF]`

Choose `a in F_2^12 \ H`. Replace `H` by `H+a`.

Then `0 notin H+a`. Moreover, non-interpolability is preserved: if `H+a subset im(q)`, then `H subset im(q+a)`, and adding a constant vector preserves coordinatewise degree <=2.

Thus we may assume the 24 target points are distinct and nonzero.

## Lemma 3 — Target-kernel code `[HUMAN_PROOF]`

Order the target points as `h_1,...,h_24` and form

`M=[h_1 ... h_24] in F_2^(12 x 24)`.

Let

`K=ker(M) subset F_2^24`.

Then:

- `dim(K) >= 24-12 = 12`;
- `d(K)>=3`.

A weight-1 kernel vector would select a zero column, impossible. A weight-2 kernel vector would equate two columns, impossible because the targets are distinct.

## Lemma 4 — An 11-dimensional even subcode `[HUMAN_PROOF]`

Let

`Even={c in F_2^24 : wt(c) is even}`.

Since `Even` has codimension 1,

`dim(K cap Even) >= dim(K)-1 >= 11`.

Choose an 11-dimensional subspace

`E <= K cap Even`.

Because `E` is even and inherits `d(K)>=3`, every nonzero word of `E` has weight at least 4.

Delete coordinates that are zero on every word of `E`. The resulting code, still denoted `E`, is a full-support even `[N,11,>=4]` code and preserves all word weights.

To bound `N`, puncture one coordinate. Because `d(E)>=4`, puncturing is injective and gives an `[N-1,11,>=3]` code. The radius-1 Hamming bound gives

`2^11 * N <= 2^(N-1)`.

This fails at `N=15` and is an equality at `N=16`. Hence

`16<=N<=24`.

Both verifiers check this off-by-one arithmetic.

## Lemma 5 — Dangerous words `[HUMAN_PROOF]`

Define

`D(E)={c in E\{0}: wt(c) in {8,12,14,16,18,20,22,24}}`.

The nonzero even weights compatible with `d(E)>=4` and length at most 24 split into

- safe weights: `{4,6,10}`;
- dangerous weights: `{8,12,14,16,18,20,22,24}`.

The purpose of this split is structural: every non-exceptional 2-dimensional subcode whose three nonzero words are dangerous has an exact-kernel realization inside the `phi_2` evaluation configuration.

## Lemma 6 — Classification of 2-dimensional weight profiles `[FINITE_EXHAUSTION]`

Let a 2-dimensional binary code have nonzero word weights `(a,b,c)`. Up to relabeling of its three nonzero words, its nonzero coordinate-type multiplicities are

`(a+b-c)/2`, `(a+c-b)/2`, `(b+c-a)/2`,

and its union support size is

`u=(a+b+c)/2`.

Thus a sorted weight triple determines the 2-dimensional code up to coordinate permutation.

Enumerating sorted triples from the dangerous weight set, requiring nonnegative integral coordinate-type multiplicities and `u<=24`, gives exactly **46** profiles.

The exact finite list is independently regenerated by both verifiers.

## Lemma 7 — Exact-kernel realization of 45 profiles `[CERTIFICATE_CHECK]`

The file

`certificate/h6_exact_profile_witnesses.txt`

contains 45 lines. Each line gives a dangerous profile and two 64-bit truth tables `f,g`.

For every line, the certificate checker verifies:

1. `wt(f), wt(g), wt(f+g)` equal the advertised profile;
2. `f,g,f+g` have algebraic degree at most 3;
3. each is directly orthogonal to all 22 degree-<=2 monomial evaluation rows;
4. if `U=supp(f) union supp(g)`, then `|U|=u` and the evaluation matrix on `U` has rank `u-2`;
5. therefore its right kernel is exactly `span(f|_U,g|_U)`;
6. because the full 64-point evaluation configuration has rank 22, one can add exactly `24-u` rank-increasing evaluation columns to obtain 24 distinct points of rank 22;
7. `f,g` vanish on all added positions, so the final 24-column evaluation matrix has exact 2-dimensional kernel spanned by the two dependencies.

The one missing profile is exactly

`(12,12,24)`.

In a 24-coordinate code, its weight-24 word is necessarily the unique all-one vector.

### Why a witness for the profile realizes the actual subcode

Any two 2-dimensional binary codes with the same sorted nonzero weights have the same three nonzero coordinate-type multiplicities, up to permuting the three nonzero codewords. Hence they are equivalent under a coordinate permutation and a change of basis of the 2-dimensional code. Reordering the 24 selected domain points transfers the witness kernel to the actual 2-dimensional subcode `L<=E`.

No hidden use of the main claim occurs here: the extension uses only the rank-22 fact for the complete `phi_2` configuration.

## Lemma 8 — A bad target forces a sum-free dangerous set `[HUMAN_PROOF + CERTIFICATE_CHECK]`

Suppose `c,d,c+d` are three dangerous nonzero words in `E` and let

`L=span(c,d) <= E <= K`.

If their profile is not `(12,12,24)`, Lemma 7 supplies 24 distinct domain points `X` with

`ker(V_X)=L`.

Since `L<=K=ker(M)`,

`ker(V_X) subset ker(M)`.

By the evaluation-equivalence theorem, `M=T V_X` for some `T`, hence the target set lies in the image of the quadratic map `q=T phi_2`. This contradicts the assumption that `H` is bad.

Therefore:

- if the length-24 all-one vector is not in `E`, then `D(E)` is sum-free;
- if the all-one vector is in `E`, then `D(E)\{1}` is sum-free, because every violation wholly inside `D(E)\{1}` has a non-exceptional profile.

## Lemma 9 — Exact Delsarte lower bounds `[HUMAN_PROOF + CERTIFICATE_CHECK]`

First take the generic branch in which `1 notin E`.

Let `A_i` be the weight distribution of the full-support even `[N,11,>=4]` code `E`. Then

- `A_0=1`;
- odd `A_i=0` and `A_2=0`;
- `sum_{i>=4, even} A_i=2047`;
- full support implies dual weight count `B_1=0`, i.e.
  `N + sum_i A_i K_1(i)=0`;
- for every `j>=2`, MacWilliams/Delsarte nonnegativity gives
  `C(N,j)+sum_i A_i K_j(i)>=0`.

For each `16<=N<=24`, the primary certificate contains exact rational numbers `alpha,beta,lambda_j` with every `lambda_j>=0` and

`F(i)=alpha+beta K_1(i)+sum_j lambda_j K_j(i) <= 1_D(i)`

at every allowed even weight.

Multiplying by `A_i` and using the constraints gives

`|D(E)| >= 2047 alpha - N beta - sum_j lambda_j C(N,j)`.

The exact certified bounds are:

| `N` | lower bound for `|D(E)|` |
|---:|---:|
| 16 | `1011` |
| 17 | `938` |
| 18 | `910` |
| 19 | `9532/11` |
| 20 | `746` |
| 21 | `4033/5` |
| 22 | `48555/56` |
| 23 | `177445/212` |
| 24 | `1680251/1865` |

Every value is strictly greater than

`5*2^(11-4)=640`.

All inequalities are checked with exact rational arithmetic; no floating-point inequality is proof authority.

## Lemma 10 — Large sum-free structure theorem `[EXTERNAL_THEOREM]`

Use the published theorem:

> If `A subset F_2^n` is sum-free and `|A|>5*2^(n-4)`, then `A` is contained in a coset of a proper subspace.

For `n=11`, the threshold is 640.

Identify the 11-dimensional code `E` with `F_2^11`. By Lemmas 8 and 9, `D(E)` is sum-free and has more than 640 elements, so

`D(E) subset x+V`

for a proper subspace `V<E`.

The coset cannot be `V` itself. Indeed, any sum-free subset `A` of a vector space `V` has size at most `|V|/2`: choose `a in A`; then `A` and `A+a` are disjoint. Since a proper subspace of an 11-dimensional space has at most 1024 points, a sum-free subset of it has at most 512 points.

Hence `x notin V`. Choose a nonzero linear functional `ell:E->F_2` with `ell(V)=0` and `ell(x)=1`. Then

`C=ker(ell)`

is a dimension-10 hyperplane disjoint from `x+V`, hence disjoint from `D(E)`.

Therefore every nonzero word of `C` has weight in `{4,6,10}`.

## Lemma 11 — No safe-weight dimension-10 code exists `[FINITE_EXHAUSTION + CERTIFICATE_CHECK]`

Delete coordinates that are zero on all words of `C`. The resulting code remains dimension 10, full support, and all nonzero weights remain in `{4,6,10}`.

Its active length `N_C` is at least 15: puncturing gives an `[N_C-1,10,>=3]` code, so the Hamming bound requires

`2^10 * N_C <= 2^(N_C-1)`.

This fails at 14 and holds at 15. The primary verifier checks the slightly larger range 14 through 24; that extra `N=14` case is harmless overcoverage, not an off-by-one dependency.

Let `A_4,A_6,A_10` be the nonzero weight counts. Necessarily

`A_4+A_6+A_10=1023`

and full support gives `B_1=0`. For every resulting nonnegative integer candidate, the verifier checks every MacWilliams coefficient

`B_j=2^(-10) * sum_i A_i K_j(i)`

for integrality and nonnegativity.

There are zero survivors for every relevant length. Thus such a code `C` cannot exist. This contradicts Lemma 10 and closes the generic branch.

## Lemma 12 — Exceptional all-one branch `[HUMAN_PROOF + CERTIFICATE_CHECK]`

Suppose `E` has length 24 and contains the all-one word `1`.

The involution

`c -> c+1`

partitions the 2048 words of `E` into 1024 complement pairs. Possible even weights compatible with `d(E)>=4` pair as

`0<->24`, `4<->20`, `6<->18`, `8<->16`, `10<->14`, `12<->12`.

Every pair contains at least one dangerous word. Hence

`|D(E)|>=1024`

and, because `1 in D(E)`,

`|D(E)\{1}|>=1023>640`.

By Lemma 8, `D(E)\{1}` is sum-free. Apply the external theorem and the same separating-functional argument to obtain a dimension-10 hyperplane `C` disjoint from `D(E)\{1}`.

Two cases remain.

### Case 12a: `1 notin C`

Every nonzero word of `C` has weight in `{4,6,10}`. Lemma 11 gives a contradiction.

### Case 12b: `1 in C`

Then `C` is automatically full support of length 24. Its only possible nonzero weights are `{4,6,10,24}`, and the unique weight-24 word occurs once.

For length 24,

`K_1(0)=24`, `K_1(24)=-24`,

so the zero word and the all-one word cancel in the `B_1` numerator. But

`K_1(4)=16`, `K_1(6)=12`, `K_1(10)=4`,

all positive. The remaining 1022 nonzero words therefore contribute a strictly positive amount, contradicting `B_1=0` for a full-support code.

The exact verifier independently confirms zero feasible enumerators.

## Conclusion `[HUMAN_PROOF]`

Both branches contradict the existence of a bad 24-point target set. Therefore every 24-set in `F_2^12` is contained in the image of a coordinatewise quadratic map. By Lemma 1, the same holds for every set of size at most 24.

Hence

`h(6) >= 25`.
